高频词小灶 · 界面设计稿 v2

7 张高保真状态稿 + 1 张标记图标稿 · 与真实应用共用同一份样式表

说明
  • 本套设计稿为 HTML 静态稿，直接引用真实应用的 ../style.css，因此所见即当前线上界面，不会随代码改动而失真。
  • 稿内不含任何交互脚本，仅用于查看与验收；点击卡片按钮可打开对应状态。
  • 每张状态稿已同步导出同名 PNG（Chrome 无头截图，1280px 宽），便于归档与分享。
  • 样例数据：单词 ability /əˈbɪləti/（能力；才能），进度「4 / 20」，轮次「第 3 轮 · 已学 60 词」。
  • 按钮位置（2026-09-24 起）：顶栏常驻「↺ 重置」+ 轮次徽标；「复习 / 学习」按钮在各视图的标题行右侧。
  • 词卡「标记」（书签）：卡片左上角，与右上角发音图标左右对称；只在中文模式与英文模式出现，背单词模式不显示。详见 08 号稿。
  • 标记模式：复习页标题行「标记」按钮进入，只显示当前模式下被标记过的词。详见 07 号稿。
  • v1 设计稿（Ardot 导出 PNG/PDF）已冻结归档于 界面设计稿v1\，不再更新。
