# 高频词小灶（xdictionary）

一个**零依赖、纯静态**的本地英语高频词学习小工具：双击 `index.html` 就能用，不需要安装、不需要联网、不需要服务器。

面向英语基础较弱的学习者：界面全中文、字号大、信息密度低，一次只学一个词。

## 功能

- **300 个 CET-4 高频词**：词库内置（`words.js`），完全离线可用
- **三种学习模式**：背单词（完整卡）/ 英文模式（隐藏释义）/ 中文模式（隐藏英文 + 默写自测）
- **翻卡与进度**：每轮 20 词，左右箭头翻卡，进度条 + 计数，15 轮循环不重复
- **词卡标记（书签）**：中 / 英文模式各存一套，跨轮、跨刷新保留
- **复习模式**：按批次复习已学词；**标记模式**：只看标记过的重点词
- **单词发音（TTS 点读）**：点卡片右上角喇叭，用浏览器原生语音朗读当前词（优先 en-US）
- **三款皮肤**：薄荷 / 暖阳米黄（换色）/ 像素风（结构级换肤 + 挥剑翻页动效 + 挥剑音效）
- **进度本地保存**：localStorage，刷新 / 关浏览器不丢

## 快速开始

方式一：`git clone https://github.com/fenghua-xueyue/xdictionary.git`

方式二：GitHub 页面 Download ZIP → 解压

然后**双击 `index.html`**，点「开始背单词」即可。无需任何安装。

> **发音提示**：点读发音使用**浏览器原生 TTS**，依赖系统已安装的英文语音包（Windows 通常自带 en-US 语音；若没有，点喇叭会提示「未找到英文语音」，不影响其他功能）。

## 技术栈

- 原生 HTML / CSS / JavaScript，**无框架、无依赖、无 CDN、无构建步骤**
- 词库通过 `<script>` 全局变量加载（规避 `file://` 下 fetch 的 CORS 限制）
- 数据存 localStorage（三个独立 key：进度 `english_app_v1` / 皮肤 `english_app_skin_v1` / 音效 `english_app_sound_v1`）
- 兼容现代 Chrome / Edge 等浏览器

## 项目结构

```
index.html          第一界面（初始空状态 → 跳学习页）
study.html          第二界面（学习 / 复习 / 标记模式 + 换肤 + 重置）
style.css           设计系统与三款皮肤
app.js              核心交互逻辑（抽词 / 翻卡 / 模式 / 复习 / 标记 / 持久化）
skin.js             换皮肤
pixel.js            像素风专用（舞台缩放 / 长词自适应）
sword.js            挥剑翻页动效 + 音效
speak.js            单词发音（TTS）
words.js            300 词词库（window.WORDS）
px-bg.svg           像素风背景
```

详细规格见 [英语高频词学习App-需求规格.md](英语高频词学习App-需求规格.md)。

## 说明

- 学习进度保存在**当前浏览器**的 localStorage 中，不同浏览器 / 设备之间不互通（未做云同步与导入导出）
- 本项目为个人学习工具，欢迎 fork 自用
